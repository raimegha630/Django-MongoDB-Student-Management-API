# Skill Lab - Django MongoDB Backend

## Overview
This project is a backend REST API developed using Django REST Framework and MongoDB. It provides authentication and management APIs for students, courses, and analytics.

## Features
- User Registration
- User Login
- MongoDB Integration
- Password Encryption using bcrypt
- Student Management
- Course Management
- Analytics APIs

## Technologies Used
- Python
- Django
- Django REST Framework
- MongoDB
- bcrypt

## Project Structure
- auth
- students
- courses
- analytics
- core
